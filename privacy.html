Privacy Policy

Politique de confidentialité – Vision Pro

1. Données collectées

Vision Pro ne collecte pas de données personnelles sensibles.
Les données traitées sont uniquement des informations publiques visibles sur les pages web consultées par l’utilisateur lors de son utilisation.

2. Utilisation des données

Les données sont utilisées uniquement pour fournir les fonctionnalités principales de l’extension (extraction et traitement d’informations visibles).

3. Stockage

Aucune donnée n’est stockée de manière permanente par l’extension. Les données peuvent être temporairement transmises à une API pour traitement.

4. Partage des données

Aucune donnée n’est vendue ou partagée avec des tiers à des fins commerciales.

5. Sécurité

Des mesures raisonnables sont mises en place pour sécuriser les échanges entre l’extension et les services externes utilisés.

6. Contact

Pour toute question, l’utilisateur peut contacter l’éditeur via la page officielle du projet.
